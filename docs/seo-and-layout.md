# Référencement et composition du portfolio

Mise à jour : 15 octobre 2026.

## Adresse publique de référence

https://talyana-rossignol-portfolio.vercel.app/

Le site Sites et le déploiement Vercel déclarent cette même URL canonique. Le site Sites conserve son audience privée. Lors de l’ajout futur d’un domaine, remplacer la base publique dans les métadonnées, les données structurées, robots.txt, sitemap.xml et les origines autorisées de l’API. Ajouter les redirections depuis l’ancienne adresse si nécessaire.

## Éléments livrés

Titre et description ciblés sur la coiffure de défilé et éditoriale à Paris ; aperçus sociaux Open Graph et Twitter ; un seul H1 ; texte de présentation explicite ; rubrique pratique visible et accessible sans JavaScript ; graphe Person, WebSite, ProfilePage et trois Service alignés sur le contenu visible. Aucun avis, prix, diplôme ou résultat inventé.

robots.txt autorise l’exploration des pages et médias, exclut /api/ et indique le sitemap. Le sitemap contient la page principale et quinze images. Les fragments de navigation ne sont pas présentés comme des pages distinctes. Les vidéos gardent preload=none ; les images sous le premier écran sont principalement différées.

Le portrait mobile remplit le cadre central après la transition. Le texte d’introduction desktop se place sous le prénom, dans une colonne latérale limitée. Sur tablette, le nom est réservé à la partie droite sous le visage. Les préférences de mouvement réduit sont conservées.

## Suivi après publication

Ajouter la propriété d’URL Vercel à Google Search Console, vérifier la propriété puis soumettre /sitemap.xml. Contrôler l’indexation de la page, les requêtes, les impressions et les clics. Aucun compte Search Console n’a été connecté ou configuré dans cette intervention.

Pour améliorer les preuves éditoriales au fil du temps, documenter les projets avec leurs titres, dates, lieux, rôle précis et crédits confirmés. Ne pas inventer ces éléments à partir d’une photographie. Le référencement et la présence dans les réponses IA ne peuvent pas être garantis.

## Vérifications

Syntaxe JavaScript, neuf tests de l’API avec prestataire simulé, validité JSON des données structurées, structure du sitemap, liens d’ancrage et disponibilité locale des médias. Pas de session de navigateur de contrôle disponible pour cette intervention ; les corrections visuelles ont été préparées à partir des captures fournies et du calcul des dimensions.
